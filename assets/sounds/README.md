# Recorded writing sounds

These bundled WAV files were normalized from audio files supplied by the app
owner on 2026-08-15. The original filenames are retained here for provenance:

- `writing_paper_soft.wav` ← `freesound_community-writing-on-paper-6988.mp3`
- `writing_paper_pencil.wav` ← `freesound_community-writing-on-paper-29376.mp3`
- `writing_paper_natural.wav` ← `freesound@_community-writing-63678.mp3`
- `writing_paper_quick.wav` ← `u_y3wk5ympz8-writing-263642.mp3`

All app assets are mono, 48 kHz, 16-bit PCM. The animation engine gates and
loops them only while the pen is touching the artwork.
